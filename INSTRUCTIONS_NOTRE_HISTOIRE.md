## 🎯 Instructions pour votre cliente

### **Étape 1 : Créer la page dans Shopify Admin**

1. **Connectez-vous à Shopify Admin** : https://admin.shopify.com
2. Dans le menu de gauche, cliquez sur **"Boutique en ligne"** → **"Pages"**
3. Cliquez sur le bouton **"Ajouter une page"** (en haut à droite)

---

### **Étape 2 : Configurer la page**

**Titre de la page :**
```
Notre Histoire
```

**Handle (identifiant) :** **TRÈS IMPORTANT**
```
notre-histoire
```
⚠️ **Le handle DOIT être exactement "notre-histoire" (avec tiret, en minuscules)**

---

## 🎨 Conseils de mise en forme

### **Pour mettre du texte en gras :**
Sélectionnez le texte → cliquez sur le bouton **B** (gras)

### **Pour mettre du texte en couleur :**
Passez en mode HTML (bouton `<>`) et utilisez :
```html
<span style="color: #077532;">Votre texte en vert</span>
<span style="color: #582900;">Votre texte en marron</span>
```

### **Pour ajouter un titre :**
```html
<h3 style="font-size: 2rem; font-weight: bold; margin-top: 3rem;">Votre titre</h3>
```

### **Pour ajouter un paragraphe :**
```html
<p>Votre paragraphe de texte.</p>
```
